#### 费马定理及其几何意义

可导而且取到极值，则在这个点上的导数值为 0

如果函数在一个点的导数取 0 则称之为这个点为驻点

取到极值点地方的切线如果不是垂直 x 轴，就一定和 x 轴平行

#### 罗尔定理及其几何意义

闭区间连续，开区间可导，两端点函数值相等

#### 拉格朗日定理及其几何意义

闭区间连续，开区间可导

又叫有限增量定理，微分中值定理

#### 柯西中值定理

### 微分中值定理的重要作用

微分中值定理建立了函数增量，自变量增量和导数之间的关系。由于函数的很多性质可用自变量增量和函数增量的关系进行描述，因此微分中值定理是研究函数性质的重要工具。

### 函数为常数的条件和函数恒等式的证明

#### 函数为常数的充要条件

闭区间连续为常数等价于在这个闭区间的导数为 0

开区间可导为常数等价于在这个开区间的导数为 0 （必要性证明可以使用拉格朗日定理）

#### 两个函数恒等的条件

两个函数在闭区间连续，开区间可导，在闭区间上函数恒等等价于任意开区间上的点两者导数相等而且存在闭区间上的一点使得两者函数值相等。

#### 函数的单调区间的一般求法

1. 首先求出驻点和不可导的点，也就是函数导数值为 0 和导数不存在的点（只有驻点和不可导的点可能是单调区间的分界点）

3. 最后讨论区间上导数的符号

#### 极值点的必要条件

由此可知驻点和不可导点只是可能是极值点，不一定就是极值点，需要使用下面点充分判别法进行判断这样。

#### 函数极值的一般求法

1. 首先求出驻点和不可导的点（也就是导数值为 0 和不存在的点）
2. 然后考察这些点两侧的导数的符号，使用第一判别法进行判断得出结论
3. 如果说二阶导数好求，且二阶导数在驻点处不为零的时候，可以使用极值第二判别法进行判断
