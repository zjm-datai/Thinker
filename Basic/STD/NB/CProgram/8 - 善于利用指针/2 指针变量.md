
存放地址的变量是指针变量，它用于指向另一个对象（如变量，数组，函数等）。那么，怎样定义和使用指针变量呢？

### 使用指针变量的例子

例 8.1 通过指针变量访问整型变量

```c
#include<stdio.h>
int main() {
	int a = 100, b = 10;
	int *pointer_1, *pointer_2;
	pointer_1 = &a;
	pointer_2 = &b;
	printf("a=%d, b=%d\n", a, b)
	printf("*pointer_1=%d, *pointer_2=%d\n", *pointer_1, *pointer_2);
}
```

程序中有两处出现 `*pointer_` ，二者的含义不同。程序第 4 行的表示定义两个指针变量。它们前面的星号只是表示该变量是指针变量。程序最后的代表的是指针变量 `pointer_` 所指向的变量。

### 怎样定义指针变量

指针变量前面的 `*` 表示该变量为指针类型变量。指针变量名是 pointer_1 和 pointer_2 。

在定义指针变量时必须指定基类型

### 指针变量作为函数参数

函数的参数不仅可以是整型，浮点数，字符型等数据，还可以是指针类型。它的作用是将一个变量的地址传送到另一个函数中。

例 8.3 对输入的两个整数按照大小顺序输出。

```c
#include<stdio.h>
void swap(int *p1, int *p2) {
	int temp;
	temp = *p1;
	*p1 = *p2;
	*p2 = temp;
}

int main() {
	void swap(int *p1, int *p2);
}
```
