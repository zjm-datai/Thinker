
### 局部 JS 变量

在 JS 函数内部声明的变量（使用 var）是局部变量，所以只能在函数内部访问它。

可以在不同的函数中使用名称相同的局部变量，因为只有声明过该变量的函数才能识别出该变量。

只要函数运行完毕，本地变量就会被删除。

### 全局 JS 变量

在函数外声明的变量是全局变量，网页上的所有脚本和函数都可以访问它。

### JS 变量的生存期

JS 变量的生命期从它们被声明的时间开始，局部变量会在函数运行以后被删除，全局变量会在页面关闭后被删除。

## JS 作用域

作用域是可访问变量的集合

### JS 作用域

在 JS 中，对象和函数同样也是变量。

**在 JS 中，作用域为可访问变量，对象，函数的集合。**

在 JavaScript 里，函数作用域意味着在函数内部声明的变量，只能在该函数内部被访问，外部无法访问。当你在函数内部对变量进行修改时，若这个变量是在函数内部声明的，那么修改的就是这个局部变量；若函数内部没有声明该变量，它就会向上级作用域查找，可能修改全局变量或者上级函数作用域中的变量。

## 事件

HTML 事件是发生在 HTML 元素上的事情。当 HTML 页面中使用 JS 的时候，JS 可以触发这些事件。

### HTML 事件

HTML 事件可以是浏览器行为，也可以是用户行为。以下是 HTML 事件的实例：

- HTML 页面完成加载
- HTML input 字段改变的时候
- HTML 按钮被点击
