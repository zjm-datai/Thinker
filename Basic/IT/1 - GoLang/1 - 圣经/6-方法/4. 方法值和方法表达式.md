
我们经常会直接使用 p.Distance() 这样的形式在同一个表达式中选择方法并执行，但其实把这两步分开做也是可以的。

这里的 p.Distance 叫做选择器，它的作用是返回一个方法值 -- 这个值本质上是把 Point 类型的 Distance 方法和特定的接收器变量 p 绑定在一起形成的函数。

这个绑定后的函数调用的时候不用再指定接收器（因为前面已经绑定了 p），只需要传入函数本身需要的参数就行：

```go
p := Point{1, 2}  // 定义一个Point类型的变量p，坐标是(1,2)
q := Point{4, 6}  // 定义另一个Point类型的变量q，坐标是(4,6)

// 把p的Distance方法绑定到p上，得到方法值distanceFromP
distanceFromP := p.Distance        
// 调用distanceFromP，传入参数q，实际就是计算p到q的距离，结果是5
fmt.Println(distanceFromP(q))      // "5"

var origin Point                   // 定义原点origin，坐标是(0,0)
// 调用distanceFromP，传入参数origin，计算p到原点的距离，结果是√5≈2.236...
fmt.Println(distanceFromP(origin)) // "2.23606797749979", sqrt(5)

// 把p的ScaleBy方法绑定到p上，得到方法值scaleP
scaleP := p.ScaleBy 
scaleP(2)           // 调用scaleP，传入参数2，p的坐标变成(2,4)
scaleP(3)           // 再传入3，p的坐标接着变成(6,12)
scaleP(10)          // 再传入10，p的坐标最终变成(60, 120)
```

当一个包的 API 需要传入一个函数值，而调用者想传入的是某个已经绑定了具体对象的方法时，方法 “值” 就非常好用了（这么说确实有点绕）。

举个例子，time.AfterFunc 这个函数的作用是：在指定的延迟事件过后，执行一个函数。假设这个函数是一个 Rocket 对象 r：

```go
type Rocket struct { /* ... */ }  // 定义一个Rocket类型（具体结构省略）
func (r *Rocket) Launch() { /* ... */ }  // 为Rocket指针类型定义Launch方法（具体实现省略）

r := new(Rocket)  // 创建一个Rocket对象，r是指向它的指针
// 用匿名函数的方式，让AfterFunc在10秒后调用r.Launch()
time.AfterFunc(10 * time.Second, func() { r.Launch() })
```

如果我们直接使用方法值传入 AfterFunc，代码会更加简洁：

```go
time.AfterFunc(10 * time.Second, r.Launch)
```

和方法值相关的还有方法表达式。

调用方法的时候，和调用普通函数不同，我们必须用选择器（比如 p.Distance）来指定方法的接收器。但是方法表达式不一样：当 T 是一个类型的时候，T.f 或者 `(*T).f` 这种写法会返回一个函数值，这个函数会把第一个参数当作接收器，所以调用时可以用普通函数的方式（不用写选择器）：

```go
p := Point{1, 2}  // 定义 Point 对象 p
q := Point{4, 6}  // 定义 Point 对象 q

// 方法表达式：Point.Distance返回一个函数，第一个参数是接收器（Point类型）
distance := Point.Distance  
// 调用这个函数，传入 p 作为接收器，q 作为参数，计算 p 到 q 的距离
fmt.Println(distance(p, q))  // 输出"5"

// 打印这个函数的类型：接收两个 Point 参数，返回 float64
fmt.Printf("%T\n", distance) // 输出"func(Point, Point) float64"

// 方法表达式：(*Point).ScaleBy 返回一个函数，第一个参数是接收器（*Point类型）
scale := (*Point).ScaleBy
// 调用这个函数，传入 &p 作为接收器，2 作为参数，对 p 进行缩放
scale(&p, 2)
fmt.Println(p)            // 输出"{2 4}"（p的X和Y都乘以2）
// 打印这个函数的类型：接收 *Point 和 float64 参数，无返回值
fmt.Printf("%T\n", scale) // 输出"func(*Point, float64)"
```

简单来说：Point.Distance 这种方法表达式得到的函数，比原来的 Distance 方法多一个参数 -- 第一个参数就是原本的接收器，后面才是方法本身的参数。

当我们需要根据变量决定调用同一个类型的哪个方法的时候，方法表达式就很有用了。我们可以通过选择，调用不同接收器对应的方法。

```go
type Point struct{
	X, Y float64
}

func(p Point) Add(q Point) Point {
	return Point{p.X + q.X, p.Y + q.Y}
}
func(p Point) Sub(q Point) Point {
	return Point(p.X - q.X, p.Y - q.Y)
}

type Path []Point

func (path Path) TranslateBy(offset Point, add bool) {
    var op func(p, q Point) Point  // 声明 op 为一个函数变量，接收两个 Point，返回一个 Point
    if add {
        op = Point.Add  // 如果 add 为 true，op 指向 Point.Add 方法（方法表达式）
    } else {
        op = Point.Sub  // 如果 add 为 false，op 指向 Point.Sub 方法（方法表达式）
    }
    // 遍历path中的每个Point
    for i := range path {
        path[i] = op(path[i], offset)
    }
}
```
