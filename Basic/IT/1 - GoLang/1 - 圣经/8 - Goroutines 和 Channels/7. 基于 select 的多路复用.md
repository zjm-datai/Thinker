
### 基础倒计时程序

首先，我们从一个简单的火箭发射倒计时程序开始：

```go
func main() {
	fmt.Println("Commencing countdown")
	tick := time.Tick(1 * time.Second)
	for countdown := 10; countdown > 0; countdown-- {
		fmt.Println(countdown)
		<-tick
	}
	launch()
}
```

这个程序使用 time.Tick 函数创建了一个 channel，这个 channel 会每秒发送一个事件（时间戳）。程序会通过从这个 channel 接收事件来实现每秒一次的倒计时。

### 增加中断中断功能

我们希望在倒计时过程中，用户按下回车键我们就可以中断发射。为此，我们创建了一个 abort channel，并启动一个 gorountine 监听用户输入：

```go
abort = make(chan struct{})

go func() {
	os.Stdin.Read(make([]byte, 1)) // 读取一个字节
	abort <- struct{}{}
}()
```

我们创建了一个类型 chan struct{} 的通道 abort，这种类型的通道通常没有实际数据传递，只用于传递一个事件信号。

启动了一个匿名 goroutine（并发程），在这个 goroutine 中：

- `os.Stdin.Read(make([]byte, 1))` 会阻塞等待用户输入，当用户按下回车键时，会读取一个字节
- 一旦有输入（用户按下回车），就会向 abort 通道发送一个空结构体值

这样设计的作用是：

- 这个 goroutine 会一直等待用户输入
- 当用户按下回车键时，它会通过 abort 通道发送一个信号
- 主程序可以通过监听 abort 通道来检测是否有中断请求

在倒计时程序中，主程序会同时等待倒计时完成和 abort 通道的信号，哪个先发生就执行相应的处理。如果用户按下回车，abort 通道会收到信号，程序就可以中断倒计时并执行中止发射的逻辑。

这种模式是 Go 语言中处理并发事件的常见方式，通过通道在不同 goroutine 之间传递信号。

### select 多路复用

要同时等待倒计时事件和中断中断事件，我们需要使用 select 语句，它可以使用实现 channel 操作的多路复用：

```go
select {
case <-ch1:
    // 处理ch1的接收
case x := <-ch2:
    // 处理ch2的接收，并使用x
case ch3 <- y:
    // 处理向ch3发送数据
default:
    // 当所有case都不能执行时的默认操作
}
```

select 会等待其中一个 case 可以执行，然后执行相应的语句。如果没有任何 case 可以执行，且有 default 分支，则执行 default；否则会一直等待。


```go
package main

import (
	"fmt"
	"os"
	"time"
)

// launch 模拟火箭发射
func launch() {
	fmt.Println("Launching rocket! 🚀")
}

func main() {
	// 创建用于接收中断信号的通道
	abort := make(chan struct{})
	
	// 启动一个goroutine监听用户输入，用于中断发射
	go func() {
		// 读取用户输入（任意键，包括回车）
		os.Stdin.Read(make([]byte, 1))
		abort <- struct{}{} // 发送中断信号
	}()
	
	fmt.Println("Commencing countdown. Press return to abort.")
	
	// 使用NewTicker而不是Tick，以便在不需要时停止，避免goroutine泄露
	ticker := time.NewTicker(1 * time.Second)
	defer ticker.Stop() // 确保程序退出时停止ticker
	
	// 10秒倒计时
	for countdown := 10; countdown > 0; countdown-- {
		fmt.Println(countdown)
		
		select {
		case <-ticker.C:
			// 等待下一秒，继续倒计时
		case <-abort:
			// 接收到中断信号
			fmt.Println("Launch aborted!")
			return
		}
	}
	
	// 倒计时结束，执行发射
	launch()
}
```
