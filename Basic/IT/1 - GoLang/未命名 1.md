在 Go 语言中，指针是一种存储变量内存地址的变量。通过指针，我们可以直接操作这片内存地址上的数据，而不是操作这个数据的副本。

## 基本概念

### 定义和声明

使用 `*` 声明指针类型，例如 `*int` 表示指向整数的指针。

使用 `&` 操作符获取变量的内存地址。

```go
x := 42
p := &x // 获取 x 的内存地址，赋值给指针 p 类型为 *int
```

#### 解引用 dereference

使用 `*` 操作符访问指针指向的值。

```go
fmt.Println(*p)
*p = 99 // 修改指针 p 指向的值（也就是修改 x）
fmt.Println(x) // 输出：99
```

### 指针和结构体

#### 结构体指针

可以创建指向结构体的指针，通过指针访问或修改结构体字段。

使用 `.` 操作符访问字段的时候，Go 会自动解引用指针。

```go
type Person struct {
	Name string
	Age int
}

p := &Person{
	Name: "Alice",
	Age: 30
}
fmt.Println(p.Name)
p.Age = 31 // 修改 Age 字段，直接操作原结构体
```

#### 指针初始化结构体的优势

减少内存拷贝：传递结构体指针比传递结构体本身更高高效（尤其是大结构体）

修改原结构体：通过指针可以直接修改原结构体的字段

### 指针作为函数参数

#### 值传递和参数传递

值传递：函数接收参数的副本，无法修改原变量

指针传递：函数接收参数的内存地址，可以修改原变量

```go
// 值传递
func setName(p Person, name string){
	p.Name = name
}

func setName(p *Person, name string){
	p.Name = name // 自动解引用，修改原结构体
}

func main() {
    p := Person{Name: "Bob"}
    setName(p, "Alice")       // 无效修改
    fmt.Println(p.Name)       // 输出："Bob"

    setNamePtr(&p, "Charlie") // 有效修改
    fmt.Println(p.Name)       // 输出："Charlie"
}
```

### 指针和 new 函数

`new(T)` 函数创建一个类型为 T 的零值变量，并返回它的指针

```go
p := new(Person) // 创建一个 *Person 类型的指针，指向零值 Person()
p.Name = "Dave" // 直接赋值，无需先初始化结构体
fmt.Println(p) // 输出 &{Dave 0}
```

### 指针的注意事项

**空指针（nil）**：未初始化的指针值为 `nil`，解引用 `nil` 指针会导致运行时 panic。

```go
var p *int // p 为 nil 指针 // 
*p = 100 // 错误：解引用 nil 指针，panic
```

**指针与切片、映射**：
   
- 切片和映射本身是引用类型，包含内部指针，通常不需要显式使用指针。
- 但如果需要修改切片或映射本身（如重新分配内存），则需要使用指针。
