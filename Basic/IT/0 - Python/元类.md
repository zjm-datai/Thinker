
在 python 中，一切都是对象，包括类本身。

当我们定义一个类的时候，这个类本身就是一个对象（由元类创建的对象）。

```python
class Person:
	pass

p = Person()
print(type(p)) # 输出：<class '__main__.Person'>（p 是 Person 类的实例）
print(type(Person)) # 输出：<class 'type'>（Person 类是 type 类的实例）
```

这里的 type 就是 python 中最基础的元类，所有类默认都是由 type 创建的。

元类（Metaclass）是**创建类的 “类”**，可以理解为：

- 实例由类创建
- 类由元类创建

元类的作用在于：自定义类的创建过程。例如，我们可以通过元类控制类的属性，方法，甚至修改类的结构。

### 类的创建流程

当我们使用 class 关键字定义类的时候，python 实际执行了以下的步骤：

1. 收集类中定义的所有属性和方法（存到一个字典中，也就是 attrs 的原型）
2. 调用元类的 `__new__` 方法，传入 4 个参数

- mcs ：元类本身（类似实例方法中的 self）
- name ：类的名称（字符串）
- bases ：类的父类（元组）
- attrs ：类的属性和方法（字典，键是名称，值是属性/方法对象）

3. 元类的 `__new__` 方法返回一个新的类对象

### attrs 参数的本质

attrs 就是上述步骤中存储类属性和方法的字典，例如定义一个类：

```python
class MyClass:
	x = 10

	def hello(self):
		return "hi"
```

python 会收集这些内容到 attrs 中，大概长这样：

```python
{
    'x': 10,
    'hello': <function MyClass.hello at 0x...>,
    '__module__': '__main__',
    '__doc__': None  # 如果有文档字符串会在这里
}
```

然后将 attrs 传给元类（一般是 type 或者你自己定义）的 `__new__` 方法，最终创建出 MyClass 类。

### 自定义元类中的 attrs 

当我们自定义元类的时候，会重写 `__new__` 或 `__init__` 方法，此时就可以通过 attrs 操作类的属性和方法。

例如，过滤掉所有小写字母开头的方法：

```python
class MyMeta(type):
	def __new__(mcs, name, bases, attrs):
		# 遍历 attrs，只保留大写开头的方法和属性
		filtered_attrs = {}
		for key, value in attrs.items():
			if key.startswith(('__', 'A')): # 保留特殊方法（如 __init__）和大写开头的
				filtered_attrs[key] = value

		return super().__new__(mcs, name, bases, filtered_attrs)

# 使用自定义元类
class MyClass(metaclass=MyMeta):
    def a(self):  # 小写开头，会被过滤
        pass
    
    def A(self):  # 大写开头，会被保留
        pass

print(hasattr(MyClass, 'a'))  # 输出：False（被过滤了）
print(hasattr(MyClass, 'A'))  # 输出：True（被保留了）
```
