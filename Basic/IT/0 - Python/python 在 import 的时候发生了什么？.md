
解释器在执行 import 的时候做的事情大致如下：

### 查找模块

解释器会根据 sys.path 中的路径依次查找指定名字的模块或包。先找模块名 .py 文件，如果没有找到，再找同名文件夹且包含 `__init__.py` 的包。

sys.path 中默认包含：

- 当前脚本目录
- 环境变量 `PYTHONPATH` 指定的目录
- 标准库路径
- 以及安装的第三方库路径

### 加载模块

找到对应文件后，读取文件内容并执行文件里的顶层代码。  
如果是包，则执行包目录下的 `__init__.py` 文件。

### 创建模块对象

解释器为该模块创建一个模块对象（ModuleType实例），模块里的变量、函数、类等都会作为这个对象的属性。

### 缓存模块

解释器会把模块对象缓存到 sys.modules 字典中，以后再次导入同一个模块的时候，直接从模块中拿，避免重复加载。

### 绑定名字

根据 import 语句形式，把模块对象绑定到当前命名空间中的变量名。  
比如 import models 时，当前命名空间中会有个变量 models 指向模块对象；  
from models import user 时，当前命名空间中会有个变量 user 指向 models.user 模块。

补充说明：

- 相对导入用点号表示，解释器根据当前模块所在位置解析导入路径。
- 如果模块已经在 sys.modules 缓存中，import 不会重复执行模块代码。
- 可以用 importlib.reload 强制重新加载模块。

简而言之，import 就是找到模块文件，执行文件代码，生成模块对象，缓存起来，然后绑定变量名。

---

`__all__` 是 python 模块或包中一个特殊的列表变量，主要用于控制 from module import * 语句的导入行为，明确指定哪些成员可以被导出。

若存在 `__all__` ，则只导入列表中- 指定的成员（变量、函数、类等）

若不存在 `__all__` ，则导入模块中所有不以下划线开头的公共成员
