简单说，像整数、字符串这种不可变类型，传递时看起来像传值，因为它们不能被修改。但复杂点的对象就不一样了，只要传给了函数，不管调用者愿不愿意，函数都能修改它们。

比如，把列表传给函数，函数里调用列表的修改方法：

```python
def my_func(items):
    items.append(4)

x = [1, 2, 3]
my_func(x)
print(x)  # 列表里多了个4
```

不过，被调用的函数没法像 C 语言的指针那样替换原始变量，只能修改它的内容。

同样，当一个变量赋值给另一个变量时，只是存了个引用，也就是给同一个数据起了个别名。所以，就算看起来传的是另一个变量，函数也能修改原始数据：

```python
a = [7, 6, 5]
b = a  # 给 a 起了个别名b
my_func(b)
print(a)  # a 也被改了，多了个4
```

对于列表和字典，可以传容器的副本，避免被函数影响。列表可以用切片操作（没起始和结束索引）来复制：

```python
def capitalize_items(items):
    for i in range(len(items)):
        items[i] = items[i].capitalize()

my_items = ["hello", "world"]
items_copy = my_items[:]  # 复制一份
capitalize_items(items_copy)
print(items_copy)  # 变成['Hello', 'World']
```

字典有个专门的 copy 方法来复制：

```python
def concat_pairs(items):
    for key in items:
        items[key] = f"{key}={items[key]}"

my_pairs = {"foo": 1, "bar": 2}
pairs_copy = my_pairs.copy()  # 复制一份
concat_pairs(pairs_copy)
print(pairs_copy)  # 变成{'foo': 'foo=1', 'bar': 'bar=2'}
```

自定义的类也会被调用者修改。任何接收这些类实例的函数都能访问或修改它们的内部属性：

```python
class MyClass:
    def __init__(self, value):
        self.value = value

x = MyClass(10)

def my_func(obj):
    obj.value = 20  # 修改了对象的属性

my_func(x)
print(x.value)  # 变成20了
```

当写别人会调用的函数时，除非在函数名、参数名或文档里明确说明，否则不该修改传入的可变值。也可以对收到的参数做个防御性复制，避免迭代时出问题。

调用函数时，传可变参数要小心，数据可能会被改，容易出难查的 bug。对于自己控制的复杂对象，可以加些辅助函数和方法，方便创建防御性副本。或者用更函数式的风格，尽量用不可变对象和纯函数。

要记住的点：

- Python 里参数按引用传递，接收的函数和方法能修改它们的属性
- 函数如果要修改输入参数，得通过命名和文档说清楚，否则别改
- 对收到的集合和对象做复制，能确保函数不会无意中修改数据
