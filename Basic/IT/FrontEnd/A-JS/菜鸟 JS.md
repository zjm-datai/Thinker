
## 变量

变量名是标识符，用于引用存储在变量中的数据。

在 JS 中，可以使用 `var` `let` `const` 关键字来声明变量。

- **`var`**：ES5 引入的变量声明方式，具有函数作用域。

- **`let`**：ES6 引入的变量声明方式，具有块级作用域。

- **`const`**：ES6 引入的常量声明方式，具有块级作用域，且值不可变。

### 局部 JS 变量

在 JS 函数内部声明的变量（使用 var）是局部变量，所以只能在函数内部访问它。

可以在不同的函数中使用名称相同的局部变量，因为只有声明过该变量的函数才能识别出该变量。

只要函数运行完毕，本地变量就会被删除。

### 全局 JS 变量

在函数外声明的变量是全局变量，网页上的所有脚本和函数都可以访问它。

### JS 变量的生存期

JS 变量的生命期从它们被声明的时间开始，局部变量会在函数运行以后被删除，全局变量会在页面关闭后被删除。

## 对象

JS 对象是拥有属性和方法的数据。

在 JS 中，几乎所有的事物都是对象。

>在 JS 中，对象是非常重要的，当你理解了对象，就可以了解 JS

对象是变量的容器，但是我们通常认为 JS 对象是键值对的容器。键值对通常的写法为 name: value ，键值对在 JS 对象通常称之为对象属性。

### 访问对象属性

由两种方式访问对象属性：

```
person.lastName
person["lastName"]
```

### 对象方法

对象的方法定义了一个函数，并作为对象的属性存储。对象方法通过调用 `()` 调用（作为函数）。该实例访问 person 对象的 fullName() 方法：

```js
name = person.fullName();
```

我们可以使用以下语法来创建对象方法：

```js
methodName : function() {
    // 代码 
}
```

## 作用域

指的是变量（或函数）的可访问范围，即代码中哪些部分可以读取或修改该变量。简单来说，作用域决定了变量的 “可见性”。

在 JS 中，对象和函数同样也是变量。

**在 JS 中，作用域为可访问变量，对象，函数的集合。**

在 JavaScript 里，函数作用域意味着在函数内部声明的变量，只能在该函数内部被访问，外部无法访问。当你在函数内部对变量进行修改时，若这个变量是在函数内部声明的，那么修改的就是这个局部变量；若函数内部没有声明该变量，它就会向上级作用域查找，可能修改全局变量或者上级函数作用域中的变量。

### 函数作用域

变量在函数内部声明之后，仅在该函数内部可见，函数外部无法访问。

- **对应声明方式**：使用 `var` 声明的变量具有函数作用域。

```js
function myFunc() {
	var a = 10;
	console.log(a);
}

myFunc();
console.log(a); // 报错
```

### 块级作用域

变量在代码块（使用 `{}` 包裹的区域，如 `if`、`for`、`while` 或独立的 `{}`）内部声明后，仅在该代码块内部可见，块外部无法访问。

- **对应声明方式**：使用 `let` 或 `const` 声明的变量具有块级作用域。

### 全局作用域

除了上述两种，还有 **全局作用域**：在所有函数和代码块外部声明的变量（无论用 `var`/`let`/`const`），在整个程序中都可访问。例如：

```javascript
var globalVar = "全局变量"; // 全局作用域，任何地方都可访问
let globalLet = "全局 let"; // 同样是全局作用域

function test() {
  console.log(globalVar); // 输出 "全局变量"（可访问）
  console.log(globalLet); // 输出 "全局 let"（可访问）
}
```

但需注意：全局变量应尽量少用，过多会导致变量污染和代码维护困难。

### 作用域的意义

1. **避免变量污染**：限制变量的可访问范围，防止不同部分的代码意外修改或读取不该访问的变量。
2. **提高代码安全性**：减少全局变量的使用（全局变量在整个程序中都可访问，容易被误改）。
3. **逻辑隔离**：使代码结构更清晰，不同作用域内的变量可以重名而不冲突（如函数内和函数外可以有同名变量，但互不影响）。

## 箭头函数

箭头函数是 ES6 引入的一种函数简写语法，它提供了更简洁的函数声明方式，同时具有一些和传统函数不同的特性。

### 箭头函数的基本语法

箭头函数的核心是用 `=>` 箭头替代传统的 `function` 关键字，基本形式如下：

```js
function add(a, b) {
	return a + b;
}

// 箭头函数等价写法
const add = (a, b) => a + b;
```

### 和传统函数的核心区别

#### 没有自己的 this

箭头函数不会绑定自己的 this，它的 this 继承自**外层作用域**（定义时的上下文），且永远不会改变。  

这解决了传统函数中 `this` 指向经常变化的问题（如回调函数中）。

```js
// 传统函数
const obj1 = {
	name: "传统函数",
	say: function() {
		setTimeout(function() {
			console.log(this.name); // 输出 undefined（this 指向 window/global）
		}, 100);
	}
};

// 箭头函数，this 继承自外层
const obj2 = {
  name: "箭头函数",
  say: function() {
    setTimeout(() => {
      console.log(this.name); // 输出 "箭头函数"（this 继承自 say 方法的 this）
    }, 100);
  }
};
```
