## HTML 介绍

HTML 是用于创建网页的标准标记语言。

### 什么是 HTML ？

- 超文本标记语言
- 创建网页的标准标记语言
- 描述网页的结构
- 由一系列的元素组成
- 告诉浏览器如何显示内容
- HTML 元素标记各种内容，如这是一个标题，这是一段文字，这是一个链接等

```html
<!DOCTYPE html>  
<html>  
<head>  
<title>Page Title</title>  
</head>  
<body>  
  
<h1>My First Heading</h1>  
<p>My first paragraph.</p>  
  
</body>  
</html>
```

`<!DOCTYPE html>` 声明定义该文档为 HTML5 文档。

• `<html>` 元素是 HTML 页面的根元素。
• `<head>` 元素包含有关 HTML 页面的元信息。
• `<title>` 元素为 HTML 页面指定一个标题（显示在浏览器的标题栏或页面标签中）。
• `<body>` 元素定义文档的主体，是所有可见内容的容器，如标题、段落、图像、超链接、表格、列表等。
• `<h1>` 元素定义一个大标题。
• `<p>` 元素定义一个段落。

### 什么是 HTML 元素？

HTML 文档由 HTML 元素定义。开始标签常被称为 **起始标签（opening tag）**，结束标签常称为 **闭合标签（closing tag）**。

`<html>` 元素定义了整个 HTML 文档。  这个元素拥有一个开始标签 `<html>` ，以及一个结束标签 `</html>`  

元素内容是另一个 HTML 元素（body 元素）。

## HTML 属性

属性是 HTML 元素提供的附加信息，属性通常出现在 HTML 标签的开始标签中，用于定义元素的行为，样式，内容或其他特性。属性总是以 `name="value"` 的形式写在标签内，name 是属性的名称，value 是属性的值。

### HTML 属性常用引用属性值

属性值应该始终被包括在引号内。双引号是最常用的，不过使用单引号也没有问题。

```html
<a href="https://www.runoob.com">Link</a>
<a href='https://www.runoob.com'>Link</a>
```

#### 全局属性

class ：为元素指定一个或多个类名，用于 CSS 或 JS 选择

style：用于直接在元素上应用 CSS 样式

title：为元素提供额外的提示信息，通常在鼠标悬停时显示。

#### 特定元素的属性

**`href`**（用于 `<a>` 和 `<link>` 元素）：指定链接的目标 URL。


## 元素级别

### 块级元素

会独自占据一整行空间，宽度会默认填满父元素。而且可以设置宽度，高度，内外边距等元素。

```html
<div>、<p>、<h1>~<h6>、<ul>、<ol>、<li>、<pre>、<blockquote>、<form>、<table>
```

### 行内元素

不会另起一行，仅占据自身内容所需的空间，并且无法设置宽度和高度。、

```html
<span>、<a>、<img>、<input>、<label>、<select>、<textarea>、<button>、<br>、<i>、<em>、<strong>
```

### 行内块级元素

综合了块级元素和行内元素的特性，既不会另起一行，又能够设置宽度和高度。

```html
<input>、<select>、<textarea>、<button>、<img>（默认就是行内块级元素）
```

## HTML 标题

HTML headings are titles or subtitles that you want to display on a webpage.

**Note:** Browsers automatically add some white space (a margin) before and after a heading.

### 标题很重要

搜索引擎使用标题来为网页的结构和内容建立索引。用户通常会通过标题浏览页面。使用标题来展示文档结构很重要。

`<h1>` 标题应用于主标题，随后是 `<h2>` 标题，然后是较不重要的 `<h3>` 标题，依此类推。

## HTML 语义元素

Semantic elements = elements with a meaning.

### 什么是语义元素？

语义元素能向浏览器和开发者清晰地描述其含义。

Examples of **non-semantic** elements: `<div>` and `<span>` - Tells nothing about its content.

Examples of **semantic** elements: `<img>`, `<table>`, and `<article>` - Clearly defines its content.
