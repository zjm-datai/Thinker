
多线程打印是一个经典的并发编程问题，通常涉及到多个线程按特定的顺序输出内容。下面我将通过几个常见的示例来解答这个问题：

### 示例 1：交替打印数字和字母

**题目描述**：编写两个线程，一个打印数字（1-10），另一个打印字母（A-J），要求输出结果必须交替进行，如：1A2B3C...10J 。

**解题思路**：使用 threading.Condition 实现线程间的通知机制，通过标志位控制交替执行。

```python
import threading

def print_number(condition):
    for i in range(1, 11):
        with condition: # 自动获取和释放锁
            # 等待轮到打印数字的时机
            while current[0] != 'number':
                condition.wait() # 等待条件满足
            print(i, end='')
            # 切换到字母线程
            current[0] = 'letter'
            condition.notify()

def print_letter(condition):
    for c in 'ABCDEFGHIJ':
        with condition:
            # 等待轮到打印字母的时机
            while current[0] != 'letter':
                condition.wait()
            print(c, end='')
            # 切换到数字线程
            current[0] = 'number'
            condition.notify()

# 使用列表作为可变对象存储当前标志
current = ['number']
condition = threading.Condition()

# 创建并启动线程
t1 = threading.Thread(target=print_number, args=(condition,))
t2 = threading.Thread(target=print_letter, args=(condition,))

t1.start()
t2.start()

# 等待两个线程执行完毕
t1.join()
t2.join()

print()  # 换行
```



### 示例二：按顺序打印 ABC

**题目描述**：编写三个线程，分别打印 A、B、C，要求最终输出必须是 ABCABCABC...，重复 N 次。

**解题思路**：使用 threading.Semaphore 控制线程执行顺序，每个线程获取前一个线程的信号量并释放下一个线程的信号量。

```python
import threading

def print_a(sem_a, sem_b, n):
    for _ in range(n):
        sem_a.acquire()
        print('A', end='')
        sem_b.release()

def print_b(sem_b, sem_c, n):
    for _ in range(n):
        sem_b.acquire()
        print('B', end='')
        sem_c.release()

def print_c(sem_c, sem_a, n):
    for _ in range(n):
        sem_c.acquire()
        print('C', end='')
        sem_a.release()

N = 3  # 重复次数
# 初始时只有A可以执行
sem_a = threading.Semaphore(1)
sem_b = threading.Semaphore(0)
sem_c = threading.Semaphore(0)

# 创建并启动线程
t1 = threading.Thread(target=print_a, args=(sem_a, sem_b, N))
t2 = threading.Thread(target=print_b, args=(sem_b, sem_c, N))
t3 = threading.Thread(target=print_c, args=(sem_c, sem_a, N))

# 三个线程会并行启动
t1.start()
t2.start()
t3.start()

# 等待所有线程执行完毕
t1.join()
t2.join()
t3.join()

print()  # 换行
```

Semahore 初始值设置为 1 的话，意味着拥有这个信号量的线程可以直接开始执行，而设置为 0 的话意味着会被先阻塞，直到该信号量被释放。

在 python 中 t.start() 的作用仅仅是启动线程，让线程进入就绪状态，而线程具体何时开始执行、以怎样的顺序执行，是由操作系统的线程调度器决定的，用户无法直接控制。所以这三个线程实际上是几乎同时启动的。

| 步骤  | 执行线程 | 操作                | 信号量状态    | 输出  |
| --- | ---- | ----------------- | -------- | --- |
| 1   | 线程 A | 获取 sema_a（值从 1→0） | sema_a=0 |     |
| 2   | 线程 A | 打印 'A'            |          | A   |
| 3   | 线程 A | 释放 sema_b（值从 0→1） | sema_b=1 |     |
| 4   | 线程 B | 获取 sema_b（值从 1→0） | sema_b=0 |     |
| 5   | 线程 B | 打印 'B'            |          | B   |
| 6   | 线程 B | 释放 sema_c（值从 0→1） | sema_c=1 |     |
| 7   | 线程 C | 获取 sema_c（值从 1→0） | sema_c=0 |     |
| 8   | 线程 C | 打印 'C'            |          | C   |
| 9   | 线程 C | 释放 sema_a（值从 0→1） | sema_a=1 |     |
| 10  | 线程 A | 获取 sema_a（值从 1→0） | sema_a=0 |     |
| 11  | 线程 A | 打印 'A'            |          | A   |
| 12  | 线程 A | 释放 sema_b（值从 0→1） | sema_b=1 |     |
| 13  | 线程 B | 获取 sema_b（值从 1→0） | sema_b=0 |     |
| 14  | 线程 B | 打印 'B'            |          | B   |
| 15  | 线程 B | 释放 sema_c（值从 0→1） | sema_c=1 |     |
| 16  | 线程 C | 获取 sema_c（值从 1→0） | sema_c=0 |     |
| 17  | 线程 C | 打印 'C'            |          | C   |
| 18  | 线程 C | 释放 sema_a（值从 0→1） | sema_a=1 |     |

如果没有信号量的控制，三个线程可能会随机执行，导致输出混乱（例如 ACBABC 或其他无序组合）。信号量在这里起到了 "令牌" 的作用，确保每个线程只有在获得许可后才能执行，从而实现了线程间的同步。

这种设计模式在多线程编程中非常常见，用于解决需要按特定顺序执行的任务，比如流水线作业、生产者 - 消费者模型等。

### 示例三：生产者 - 消费者模型

**题目描述**：编写一个生产者线程和一个消费者线程，生产者生成 0-9 的数字并放入队列，消费者从队列中取出数字并打印，要求使用线程安全的队列。

**解题思路**：使用 queue.Queue 作为线程安全队列，生产者和消费者通过队列进行通信。

```python
import threading
import queue

def producer(q):
    for i in range(10):
        q.put(i)
        print(f"Produced: {i}")

def consumer(q):
    while True:
        item = q.get()
        print(f"Consumed: {item}")
        q.task_done()  # 标记任务完成
        if item == 9:  # 遇到终止条件退出循环
            break

q = queue.Queue()

# 创建并启动线程
t1 = threading.Thread(target=producer, args=(q,))
t2 = threading.Thread(target=consumer, args=(q,))

t1.start()
t2.start()

# 等待生产者线程完成
t1.join()
# 等待队列中的所有任务被处理完毕
q.join()
# 等待消费者线程完成
t2.join()
```
