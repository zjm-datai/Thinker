### 结构体的定义和初始化

如何定义一个结构体并初始化它？

```go
// 定义结构体
type Person struct {
	Name string
	Age int
}

// 初始化方法
p1 := Person{Name: "Alice", Age: 30}

// 初始化方法2：按顺序赋值（需要提供所有字段）
p2 := Person{"Bob", 25}

// 初始化方法3：指针方式
p3 := &Person{Name: "Charlie"} // Age 默认为 0
```

### 结构体方法和接收器类型

结构体方法的接收器类型有什么区别？

- 值接收器： `func(p Person) SayHello()` 操作副本，不修改原结构体
- 指针接收器：`func(p *Person) SetAge()` 直接操作原结构体，修改会生效

**选择原则**：若方法需要修改结构体或处理大对象，使用指针接收器。

### 结构体继承和组合

Go 语言如何实现类似其他语言中的继承？

Go 通过组合（嵌入匿名结构体）实现代码复用：

```go
type Animal struct {
	Name string
}

func (a Animal) Eat() {
	fmt.Println(a.Name, "is eating")
}

type Dog struct {
	Animal
	Breed string
}

d := Dog{Animal: Animal{Name: "Buddy"}, Breed: "Labrador"}
d.Eat()
```

### 结构体和接口的关系

结构体如何实现接口？

如果结构体实现了接口的所有方法，则它隐式实现了该接口

```go
type Shape interface {
	Area() float64
}

type Rectangle struct {
	Width, Height float64
}

func (r Reactangle) Area() float64 {
	return r.Width * r.Height
}

// Reactangle 自动实现了 Shape 接口
```
