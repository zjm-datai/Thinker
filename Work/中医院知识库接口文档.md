## 1. 数据集（Dataset）管理

### 1.1 创建数据集 

**POST /api/v1/datasets**

创建一个新的数据集。

#### 请求

- **Method**: `POST`
- **URL**: `/api/v1/datasets`
- **Headers**:
  - `Content-Type: application/json`
  - `Authorization: Bearer <YOUR_API_KEY>`
- **Body**:
```json
{
  "name": "test_1",
  "avatar": "<base64字符串，可选>",
  "description": "<可选>",
  "embedding_model": "<可选，例如 BAAI/bge-zh-v1.5>",
  "permission": "<可选，me|team，默认 me>",
  "chunk_method": "<可选，见下方枚举>",
  "parser_config": { <对象，可选> }
}
```

#### chunk_method 可选值

```
naive、manual、qa、table、paper、book、laws、presentation、picture、one、email
```

#### parser_config 说明

- 如果 `chunk_method` 为 `naive`：
  ```json
  {
    "chunk_token_count": 128,
    "layout_recognize": true,
    "html4excel": false,
    "delimiter": "\n",
    "task_page_size": 12,
    "raptor": { "use_raptor": false }
  }
  ```
- 如果 `chunk_method` 为 `qa / manual / paper / book / laws / presentation`：
  ```json
  { "raptor": { "use_raptor": false } }
  ```
- 如果 `chunk_method` 为 `table / picture / one / email`：
  ```json
  {}
  ```

#### 示例

```bash
curl --request POST \
     --url http://{address}/api/v1/datasets \
     --header 'Content-Type: application/json' \
     --header 'Authorization: Bearer <YOUR_API_KEY>' \
     --data '{ "name": "test_1" }'
```

#### 成功响应

## 2. 数据集内文件（Document）管理

### 2.1 上传文件

**POST /api/v1/datasets/{dataset_id}/documents**

向指定数据集上传一个或多个文档。

#### 请求

- **Method**: `POST`
- **URL**: `/api/v1/datasets/{dataset_id}/documents`
- **Headers**:
  - `Content-Type: multipart/form-data`
  - `Authorization: Bearer <YOUR_API_KEY>`
- **Form 参数**:
  - `file=@{FILE_PATH}` （可多次出现，支持批量上传）

#### 示例

```bash
curl --request POST \
     --url http://{address}/api/v1/datasets/{dataset_id}/documents \
     --header 'Content-Type: multipart/form-data' \
     --header 'Authorization: Bearer <YOUR_API_KEY>' \
     --form 'file=@./test1.txt' \
     --form 'file=@./test2.pdf'
```

#### 成功响应

```json
{
  "code": 0,
  "data": [
    {
      "id": "b330ec2e91ec11efbc510242ac120004",
      "dataset_id": "527fa74891e811ef9c650242ac120006",
      "name": "1.txt",
      "location": "1.txt",
      "size": 17966,
      "type": "doc",
      "chunk_method": "naive",
      "parser_config": {
        "chunk_token_num": 128,
        "delimiter": "\\n",
        "html4excel": false,
        "layout_recognize": true,
        "raptor": { "use_raptor": false }
      },
      "created_by": "69736c5e723611efb51b0242ac120007",
      "run": "UNSTART",
      "thumbnail": ""
    }
  ]
}
```

#### 失败响应

```json
{ "code": 101, "message": "No file part!" }
```

### 2.3 下载文件 

**GET /api/v1/datasets/{dataset_id}/documents/{document_id}**

#### 请求

- **Method**: `GET`
- **URL**: `/api/v1/datasets/{dataset_id}/documents/{document_id}`
- **Headers**:
  - `Authorization: Bearer <YOUR_API_KEY>`
- **输出**:
  - 文件内容流（可直接重定向到本地文件）

#### 示例

```bash
curl --request GET \
     --url http://{address}/api/v1/datasets/{dataset_id}/documents/{document_id} \
     --header 'Authorization: Bearer <YOUR_API_KEY>' \
     --output ./ragflow.txt
```

#### 成功响应

```
This is a test to verify the file download feature.
```

#### 失败响应

```json
{ "code": 102, "message": "You do not own the dataset 7898da028a0511efbf750242ac1220005." }
```
