## 语音转文字（STT）

- **URL**：`POST http://localhost:8088/v1/audio/transcriptions`

- **请求类型**：`multipart/form-data`

- **参数**：

| 字段名        | 类型                       | 必填  | 说明                                       |
| ---------- | ------------------------ | --- | ---------------------------------------- |
| `file`     | File（`mp3`/`wav`/…）      | 是   | 待转写的音频文件                                 |
| `metadata` | JSON（`application/json`） | 是   | 转写元数据，包含 `person_id` 与 `conversation_id` |

字段说明：

元数据主要用于跟踪音频转写文件和具体的用户对话，用于后续排查

metadata 字段结构：

```
{
  "person_id": "string or UUID",
  "conversation_id": "string or UUID"
}
```


- **返回**：


```json
{
  "transcription": "识别出来的文字"
}
```

**示例：**

```bash
curl -X POST \
  'http://localhost:8088/v1/audio/transcriptions' \
  -H 'accept: application/json' \
  -F 'file=@test.mp3;type=audio/mpeg' \
  -F 'metadata={"person_id":"123456","conversation_id":"abc-def-789"};type=application/json'
```


### 错误码

| HTTP 状态码 | 错误码                      | 说明                                       |
| -------- | ------------------------ | ---------------------------------------- |
| 400      | `INVALID_METADATA`       | `metadata` 缺失或不是合法 JSON                  |
| 400      | `MISSING_FILE`           | 未提供 `file`                               |
| 415      | `UNSUPPORTED_MEDIA_TYPE` | 音频格式不支持                                  |
| 422      | `VALIDATION_ERROR`       | `person_id` / `conversation_id` 为空或格式不合法 |
| 500      | `TRANSCRIBE_FAILED`      | 服务端转写失败                                  |

## 文字转语音（TTS）

- **URL**：`POST http://localhost:8088/v1/audio/speech`

- **请求类型**：`application/json`

- **参数**：

    - `text`：要合成的文字

    - `voice`：音色名称（可以用 `FunAudioLLM/CosyVoice2-0.5B:anna`）（具体音色有待模型确定）

    - `stream`：是否流式播放（`true` 边播边下，`false` 一次性返回完整音频）

- **返回**：
    
    - 音频流（`audio/mpeg`）


**示例：**

```bash
curl -X 'POST' \
  'http://localhost:8088/v1/audio/speech' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{
  "text": "我是大帅哥",
  "voice": "FunAudioLLM/CosyVoice2-0.5B:anna",
  "stream": true
}'
```
