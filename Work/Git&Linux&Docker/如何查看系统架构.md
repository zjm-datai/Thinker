
### windows

Win+R 输入 cmd 回车，输入：

```
wmic os get osarchitecture
```

会显示 32-bit 或 64-bit 来表明系统架构

也可以输入 systeminfo 在输出结果中查找系统类型来确定架构信息

### Linux 

- **使用 uname 命令：** 打开终端，输入 uname -m 并回车，若输出为 “x86_64” 或 “amd64”，表示是 64 位的 Intel/AMD 处理器架构；输出为 “i686” 或 “i386”，则是 32 位的 x86 架构；输出为 “aarch64” 或 “arm64”，是 64 位的 ARM 架构；输出为 “armv7l” 或 “armhf”，是 32 位的 ARM 架构。

- **使用 lscpu 命令**：在终端中输入 “lscpu”，会显示 CPU 架构、线程、核心数量等相关信息，能更详细地了解 CPU 架构情况。
