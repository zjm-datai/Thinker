
#### 暂存本地修改

```
git stash 
```

这条命令会把当前工作目录的修改（包括已跟踪文件的修改和暂存区的内容）保存起来，并恢复到干净的工作状态。

#### 拉取远程更新

```
git pull
```

这会将远程分支的最新更改拉取到本地。

#### 恢复暂存的修改

```
git stash pop 
```

恢复刚才保存的本地修改，并将 stash 条目删除。

#### 提交本地修改

```
git add .
```

```
git commit -m "你的提交说明"
```

将提交推送到默认的远程分支

```
git push
```

或者指定远程和分支

```
git push origin main
```

> 如何查看当前远程仓库地址

```
git remote -v
```

> 查看当前所在的本地分支

```
git branch 
```

```
* main
  dev
```

带 `*` 的表示当前所在分支。

> 查看所有的远程分支

```
git branch -r
```

```
origin/HEAD -> origin/main
origin/main
origin/dev
origin/feature/login
```

- `origin/HEAD -> origin/main`：代表默认远程分支是 `main`。
- 其他如 `origin/dev`、`origin/feature/login` 是远程存在的分支。

> 查看本地分支跟踪的远程分支

```
git branch -vv
```

```
* dev-his 12da284 [origin/dev-his: behind 3] 智能问答-弹出图片-测试 url 写死
```
