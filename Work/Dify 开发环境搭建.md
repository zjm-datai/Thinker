```
cursor.execute(statement, parameters)
sqlalchemy.exc.ProgrammingError: (psycopg2.errors.InsufficientPrivilege) permission denied to create extension "uuid-ossp"
HINT:  Must be system admin to create this extension.
```

**`uuid-ossp` 扩展只能由超级用户（SUPERUSER）创建或安装**，一个普通用户即使有建表权限，也无法执行 `CREATE EXTENSION`。[Stack Overflow 上的多个用户证实了这一点] 

我们需要使用超级用户身份安装扩展：

```
vsql -U vastbase -d dify_test -p 5432
```

```
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
```

```
GRANT USAGE ON SCHEMA public TO dify_test;
GRANT EXECUTE ON FUNCTION uuid_generate_v4() TO dify_test;
```
