手动复制公钥文件 id_rsa_windows.pub 的内容，然后登陆到远程服务器并将内容粘贴到 authorized_keys 文件。

在远程服务器上，authorized_keys 文件通常存储在用户的 .ssh 目录中。具体路径可能为 ~/.ssh/authorized_keys 。

```
# Read more about SSH config files: https://linux.die.net/man/5/ssh_config
Host 联通云
    HostName 211.90.240.240
    User root
    Port 22
    IdentityFile "C:\Users\28361\.ssh\id_rsa_windows"
```

一定要注意这里的路径要加 "" 不然不行。
